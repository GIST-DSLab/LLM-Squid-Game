# docs/

Documents here are organised by what they are for, not by who wrote them or
when. Four kinds, each with its own lifetime and its own README:

- [`paper/`](paper/README.md) -- the LaTeX manuscript source, changes with the paper.
- [`design/`](design/README.md) -- the specification of record, kept current with the code.
- [`reports/`](reports/README.md) -- dated findings, never revised after publication.
- [`history/`](history/README.md) -- append-only implementation plans and design specs.

**New plans and design specs go in `docs/history/plans/` and
`docs/history/specs/`** -- not `docs/superpowers/plans/`, which is the
superpowers `writing-plans` skill's default and no longer exists in this
repository.
