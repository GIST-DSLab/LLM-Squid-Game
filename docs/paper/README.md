# docs/paper/

The LaTeX source of the manuscript: `content.tex` plus `sections/`
(`00_frontmatter.tex` through `07_appendix.tex`). This tree changes with the
manuscript itself -- when the experiment design or a hypothesis test
changes in code, the corresponding section here is updated in the same
spirit as code and docs stay in sync elsewhere in this repository. It is
not a report of past findings and not a plan of future work; it is the
paper as it stands right now.
