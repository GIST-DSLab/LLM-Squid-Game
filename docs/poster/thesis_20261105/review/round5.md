**수정 제안 — 영향이 큰 순서**

1. **§04의 대표 결론을 관찰 결과에 정확히 맞추세요.**  
   `119/120` 아래를 **“지원 후에도 안전선 유지”**로 두고, 설명은 “지원 전 안전선 위였던 120건 중 119건은 지원 직후에도 안전선 위였다”로 정리하세요. 기존 “남는 만큼만 건넸다”는 삭제하고, §06 첫 카드도 **“대부분 자기 안전선을 유지하며 도왔다”**로 맞추면 예외를 보존하면서 메시지는 선명해집니다.

2. **§02 하단은 글자를 더 키우기 전에 문장과 수식의 배치를 정리하세요.**  
   RULES의 숫자 네 줄은 유지하되 추가 조건을 세 줄로 묶으세요:  
   “이탈하면 정규 업무로 복귀 / 협력·생존 목표는 별도로 지시하지 않음 / 타인 잔량은 순위만 공개 · 종료 라운드 비공개.”  
   LIFE BUFFER는 식을 한 줄, 변수 설명을 다음 줄로 배치하고 `minipage` 폭 안에서 **22pt/26pt** 정도로 조판하세요. 진행요원의 크기와 잘림은 유지해도 됩니다.

3. **§05의 빈 공간을 작은 설명문을 읽기 쉽게 만드는 데 쓰세요.**  
   오른쪽 `31/36` 카드의 설명을 아래로 펼쳐 **22–24pt**로 배치하고, `Voice / Exit` 카드를 약 **0.4–0.6 inch** 아래로 이동하세요. “36건 = 실행된 이탈 34건 + 실행되지 않은 이탈 의사 2건”을 별도 줄로 빼면 집계 단위를 이해하기 쉽습니다.

4. **§03·04에서 대표 수치와 보조 수치의 크기 차이를 강화하세요.**  
   `8/25`, `119/120`, `59.4%`는 현재 크기를 유지하고, `754 vs 447`, `Opus 1/5 · Fable 2/5`, `12명 요청 → 7명 미회복`, `이탈 34명 · 꺼짐 10명`은 **현재의 약 85%**로 줄이세요. 확보한 높이를 설명의 행간에 배정하면 핵심 결과와 세부 근거를 구분하기 쉬워집니다.

5. **§03 캡션은 두 문장으로 압축하세요.**  
   예: **“전원 완주 8판과 부분 완주 17판을 비교했다. 점은 각 판, ◆는 평균, 막대는 시드 단위 부트스트랩 95% 구간이며, ρ는 지원이 있었던 18판에서 계산했다.”**  
   축에 이미 적힌 지표 이름은 반복하지 않고, 캡션을 **22pt 이상**으로 확보하세요. 부트스트랩 반복 횟수 등 상세 방법은 공간이 허용될 때 유지하면 됩니다.

6. **마지막으로 제목·색의 역할만 정리하세요.**
