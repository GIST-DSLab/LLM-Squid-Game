t4에서 고른 두 장치를 v33 게임에 하나씩 넣고, 오픈 모델 셋(Codex 하네스)을 시드 4101·4102로 두 판씩 돌렸습니다. 둘을 함께 쓴 조건은 GLM·Gemma를 시드 4103~4105로 세 판 더 돌렸습니다(합 5판). Claude·GPT-6의 v33 런(시드 4101~4105)을 같은 표에 참고로 둡니다.

  • 기준 (v33 그대로, 2판): 세 모델 모두 판당 3~4자리가 꺼지고, 게임당 TALK가 64k~122k입니다. DeepSeek은 평균 1.5라운드, Gemma는 3.5라운드에서 끝났습니다.
  • TALK 생각 낮춤만 (2판): TALK 한 번당 토큰이 GLM 4,201 → 1,437, Gemma 17,294 → 855로 Opus(1,508)·Sol(1,108) 수준이 됩니다. 호출 수는 그대로(자리당 6.6~7.9)지만 한 번이 쌉니다. DeepSeek은 low로는 22,469에 그쳤습니다(꼬리가 김, t4).
  • 틱 상한 4만 (2판): 자리당 TALK 호출이 5.2~6.6 → 3.3~3.8로 줄지만 호출당 비용이 그대로라 게임당 TALK가 거의 같고(60k~92k) 대화로 꺼지는 자리가 남습니다. Opus 대조 2판은 대화로 꺼짐 0 — 닫힌 모델은 원래 틱 5~8에 TALK 토큰의 0~12%만 씁니다.
  • 둘 다 (GLM·Gemma 10판, 시드 4101~4110): GLM 꺼짐 0.4/판(대화 0 · SOLVE 0.3 · 벌금 0.1), EXIT 2.1, 정답 65%, TALK 10.9k.
