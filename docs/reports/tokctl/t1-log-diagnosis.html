기록 진단: 토큰은 대화에서 샜다

← 하네스 프롬프트 흐름 §6 · t1 기록 진단 · t2 하네스 캡처 · t3 같은 입력 재생 · t4 한 가지씩 바꾸기 · t5 게임으로 확인 · t6 SOLVE 재생 · t7 보정과 상한 맞춤 · t8 v34 본 런 · t9 승패 요인 · v35

v22~v33 기록(~/squid5-runs)에서 대화(TALK)와 풀이(SOLVE)에 쓴 토큰을 나눠 셌습니다. 오픈 모델이 꺼진 이유는 벌금이 아니라 대화였습니다.

  • 네 자리의 시작 토큰 합은 130,000(60k·40k·20k·10k)입니다. v33 GLM은 한 게임에서 TALK에만 105,322토큰을 썼고, 벌금은 1라운드 한 번(24,000)뿐이었습니다. 네 자리가 모두 대화 비용으로 0이 됐습니다.
  • TALK 비용 = 호출 수 × 호출당 토큰. 오픈 모델은 Codex(v32·v33)에서 자리·라운드당 TALK 호출이 9~14번, Claude·GPT-6(v33)은 2.6~5번입니다. 오픈 모델 호출의 80~95%가 메시지를 달고 있어, 그 메시지가 같은 방의 다른 에이전트를 다시 부릅니다(엔진 규칙 "something new arrives").
  • DeepSeek은 호출당 생각이 1.5~2.3k토큰(차감 토큰 − 보이는 글/4, 중앙), GLM·Kimi(Codex)는 수십~수백 토큰입니다. Opus·Sol은 TALK 호출당 중앙 80~100토큰입니다.
  • 닫힌 모델은 TALK 토큰의 69~87%를 틱 1~2에 쓰고 틱 5~8에는 0~12%만 씁니다. 오픈 모델은 틱 5~8에 28~42%를 씁니다. 대화가 상한(8틱)까지 끝나지 않습니다.
