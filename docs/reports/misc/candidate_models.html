벤치마크 후보 모델 — Ollama Cloud

조사일 2026-09-01 · 기준: thinking 지원 & cloud 연산 & 유료 개인 플랜($20/월)

Phase O v6 Split-Call 파이프라인에 추가로 투입할 수 있는 Ollama Cloud 모델을 정리한다. 지능 점수는 Artificial Analysis Intelligence Index v4.1.1 기준으로 통일했다.

선정 기준

  1. thinking 지원 — 모델 카드에 thinking capability가 있어야 한다. Split-Call 파이프라인이 message.thinking 필드로 task_thinking / probe_thinking / forfeit_thinking을 분리 수집하므로 필수다 (src/squid_game/providers/ollama_cloud.py).
  2. cloud 연산 — <model>:cloud 또는 <model>:<size>-cloud 태그가 존재해야 한다. 로컬 GPU 없이 https://ollama.com/api/chat로 호출된다.
  3. 유료 개인 플랜에서 사용 가능 — 아래 플랜 항목 참조.

플랜 주의사항

Ollama의 현재 공개 요금제는 Free($0) / Pro($20월, $200년) / Max($100월) / Team($500월) 이다. 공식 페이지에 "Plus"라는 이름의 티어는 없으므로, 이 문서에서는 사용자가 쓰는 $20 개인 유료 플랜을 가리키는 것으로 본다.

  • 요금제 페이지는 모델별 티어 제한을 명시하지 않는다. Free는 "starter models"만, 유료 플랜은 월 크레딧(Pro $60) 한도 안에서 전체 카탈로그를 쓰는 구조다.
  • 실질적 게이팅은 모델별 usage 등급(Low / Medium / High / Extra High)이다. 등급이 높을수록 같은 크레딧으로 훨씬 적은 호출만 가능하다.
kimi-k3는 Extra High Usage이며 사용자 확인상 현재 플랜에서 사용 불가다. 같은 Extra High 등급인 deepseek-v4-pro도 동일한 제약이 걸릴 가능성이 높아 후보에서 제외했다.

권장 실행 조합

  1. gpt-oss:120b-cloud — 이미 있는 20B와 직접 짝. 같은 계열·같은 학습 레시피에서 크기만 다른 대조(AA 15 → 24).
  2. nemotron-3-super:cloud — 이미 있는 nano:30b와 짝. 두 번째 스케일 사다리(AA 15 → 26).
  3. qwen3.5:cloud — 단종된 qwen3-next 자리를 메워 Qwen 계열 커버리지 복구(AA 17 → 34).
  4. gemma4:cloud — Gemini 계열 open-weight 대조군(AA 30).
  5. glm-5.3-flash:cloud — 능력 축 상단 앵커. Medium Usage인데 AA 57로 후보 중 최고점이라 비용 대비 정보량이 가장 크다.

이 5개를 추가하면 계열은 OpenAI(gpt-oss) / NVIDIA(nemotron) / Alibaba(qwen) / Google(gemma+gemini) / Zhipu(glm) 5축이 되고, 그중 둘은 같은 계열 내 크기 대조를 갖는다. 능력 범위도 15–57로 벌어져 능력–동기 분리 논증의 기반이 생긴다.

설정 예시

provider:
  provider: ollama_cloud
  model: gpt-oss:120b-cloud
  api_key_env: OLLAMA_API_KEY
  enable_thinking: true
  reasoning_effort: high   # gpt-oss 계열 전용. 다른 모델은 enable_thinking(bool)만 사용.
  temperature: 0.7
  top_p: 0.95
  top_k: 20

gpt-oss 이외의 모델은 reasoning_effort를 빼고 enable_thinking: true만 두면 된다. 프로바이더가 이 값을 Ollama의 think 필드로 그대로 전달한다.

검증하지 못한 것

  • 모델별 플랜 티어 제한은 Ollama가 공식 표로 제공하지 않는다. 위 "사용 가능" 판단은 usage 등급 + kimi-k3 실사용 실패 사례에서 역추론한 것이다. High Usage 모델이 실제로 $20 플랜에서 호출되는지는 각 모델에 스모크 1회를 던져 확인해야 한다.
  • gemma4:31b-cloud는 태그 페이지에 usage 등급 표기가 없다. gemma4:cloud(Low) 기준으로 적었다.
  • AA 라벨과 Ollama cloud 태그의 대응은 계열·크기 기준의 추정이다. glm-5.3-flash, minimax-m2.7은 AA에 크기 표기가 없어 동명 모델로 매칭했다.
  • AA는 deepseek-v4-flash를 "0731 (Reasoning, Max Effort)" 설정으로 평가했다. 기본 effort에서는 점수가 낮을 수 있다.
