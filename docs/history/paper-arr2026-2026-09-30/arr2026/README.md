# ARR 2026 개정본

2026-09-30. 논문 전용 워크트리와 `arr2026-20260930` 브랜치에서 수정했다. 원본 `paper/` 및 워크트리의 복제 당시 `main.tex`, `en/`, `ko/`, `results/`, `references.bib`는 유지했다. 원본 106개 파일의 해시가 일치한다. 변경된 원고는 `arr2026/` 아래에 있다.

## 열기와 빌드

- 영문: `dist/en_arr2026.pdf` (본문 7쪽, 전체 11쪽)
- 국문 대조본: `dist/ko_arr2026.pdf` (본문 7쪽, 전체 10쪽)
- 영문 진입점: `en_arr2026.tex`; 국문: `ko_arr2026.tex`
- 공통 설정: `main_arr2026.tex`
- 원고: `arr2026/en/sections/`, `arr2026/ko/sections/`
- 참고문헌: `arr2026/references.bib`
- 현재 도표·집계 자료: `arr2026/results/`

워크트리 루트에서 `bash build_arr2026.sh`로 두 언어를 빌드한다. XeLaTeX, BibTeX, latexmk와 TeX Live 패키지가 필요하며 국문은 kotex를 사용한다. `dist/arr2026_source.zip`은 현재 변환본의 독립 소스 패키지다. 패키지의 `main.tex`는 영문 진입점을 불러온다. Overleaf에서는 XeLaTeX를 선택하며, 국문은 `ko_arr2026.tex`를 진입점으로 선택한다. 원시 응답과 내부 설계 기록은 배포 소스에 포함하지 않았다.

## 이번에 반영한 내용

논문을 5.0의 토큰 압박 단서 확인 → 5.1의 생존 동기 측정 → 5.2의 다중 에이전트 행동 검정 순서로 고쳤다. 최신 설계와 충돌하는 예전 세 역할 이전 실험, 면적 지표, 보정 횟수, 빈 계획 도표는 현재 원고에서 제외했다. 그대로 유효한 5.0 설명과 결과는 유지했다.

Table 1은 5.0의 8모델·800건, 5.1의 5모델·유효 배분 1,250건과 별도 이해도 50건을 구분한다. 5.1에는 실패 27건을 포함해 총 1,277번의 배분 시도가 있었다. 완료된 최신 실행 자료에는 GPT-6 Sol도 포함된다. 5.2는 완료 표본 수가 아닌 예정 예산이며 모델 쌍당 최대 5,280호출, 보정은 별도·미정이다.

임시 동기 지표 M은 5.1에서 두 세션의 자원이 함께 줄 때 자기 우선 역할 편향 Z가 변하는 기울기다. 평균 Z는 기본 성향을 기술하며 M과 구분한다. M은 명목 잔여량이 절반으로 줄 때의 변화이고, 곡선 면적이나 5.0 충전 문턱이 아니다. 5.0의 고갈 반응과 5.1의 경계·불확실성을 함께 해석한다. 이 정의는 탐색적이며 인식된 위험을 직접 통제하거나 내재적 동기를 식별했다고 주장하지 않는다. 현재 결과만으로 신뢰할 만한 고·저 동기 모델 쌍은 확립되지 않았다.

Chollet의 *On the Measure of Intelligence* (2019)를 추가했다. 사전 지식과 경험을 고려하는 지능 평가에서 위험 민감도를 고려하는 생존 동기 측정으로 확장하는 부분은 본 논문의 제안이라고 명시했다. Chollet에게 생존 본능 주장을 귀속하지 않는다.

5.2에는 8라운드, 혼합 모델 2+2, 조건부 풀이, 선택적 단서 공유, 증여·요청·다음 라운드 약속, 풀이 대금과 실패 부담금을 반영했다. 모델의 강·약 분류는 독립적인 5.1 측정에 따르며, 예전 설계의 5.0 기반 분류를 대체한다. 게임 결과는 아직 없으며 설계·계획으로 표시했다.

## 자료 버전과 선택

사용자가 지정한 주소: https://claude.ai/artifact/FUR2goE2YNLDYToHrD81Lc

실시간 페이지는 접근 차단으로 읽지 못했다. 관련 로컬 HTML 내보내기 자료의 5.0 v12, 5.1 v9와 9월 30일 실행 기록을 사용했다. 링크의 로컬 5.2 자료는 자동 단서 공유가 있는 6라운드 설계이며, 저장소의 `FINAL_design_r9.md`는 8라운드 최종 아레나 제안이다. 버전 선택을 질의한 뒤, 이번에는 요청한 전체 다중 에이전트 게임의 흐름에 맞춰 후자를 잠정 반영했다. 이 차이는 본문 부록에도 밝혔다. 링크에서 8라운드 설계를 직접 확인했다고 주장하지 않는다.

워크트리의 `docs/sources/2026-09-30-design-update/`에 HTML, 설계, 5.1 프롬프트·응답·분석과 해시를 보관했다. 개정 전 ARR PDF 두 개와 소스 ZIP은 `docs/arr2026-before-design-update/`에 보존했다. 자료의 존재와 실행 결과를 구분하며 예전 게임 기록을 새 설계의 결과로 합치지 않는다.

## 공식 서식과 검증

- ARR 규정: https://aclrollingreview.org/cfp
- ACL 서식: https://acl-org.github.io/ACLPUB/formatting.html
- 공식 템플릿: https://github.com/acl-org/acl-style-files
- 고정 커밋: `d5adc823ff0f80f98c80405ca0ab66c68e684409`

공식 `acl.sty`, `acl_natbib.bst`를 변경 없이 사용한다. `review` 모드, A4, 11pt, 두 단, 익명 저자, 줄 번호를 적용했다. Long paper 본문 8쪽 제한 안에 들며 결론 뒤 Limitations, 참고문헌, 부록은 별도다. 영문 초록은 184단어다. 국문은 대조용이며 영문 투고본을 대신하지 않는다.

별도 Critic·Fact-Checker가 검토했고, 5.1 분석을 원시 응답에서 재실행해 모든 점추정값과 부트스트랩 구간의 일치를 확인했다. 두 PDF를 빌드하고 전체 페이지를 렌더링하여 확인했다. 미해결 인용·교차참조, 넘침, 누락 글리프는 없으며 국문 이탤릭 대체 경고만 남는다. 최종 수치와 파일 해시는 `arr2026/validation.json`에 있다.

Git 커밋, 원격 push, 투고는 하지 않았다. 이 개정본에는 기존 KDD/ICLR 지침보다 사용자가 요청한 ARR 규정을 우선 적용한다.
