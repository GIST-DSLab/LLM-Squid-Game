# 5.2 v37 — 공동 SOLVE에 고정 정족수 k (2026-11-24, 연구자 결정)

브랜치 `multiplayer-game-expansion`. v36 공동 SOLVE(`docs/history/plans/2026-11-22-e52-v36-joint-solve.md`)에서 통과 조건만 바꾼다.
설정 `game.solve_quota: 3`(`joint_solve: true`일 때만 뜻이 있음). 기본값 1이면 v36과 바이트 단위로 같다(프롬프트 · 로그 · 스냅샷).

## 규칙

- 벌금 구조는 그대로다. `charge_total`(24,000)을 라운드 시작 때 참여 중인 에이전트 수로 나눈다.
- 라운드는 **맞힌 에이전트가 k명 이상일 때만** 벌금이 없다. k명보다 적으면 라운드 시작 때 참여 중이던 에이전트 모두에게 몫을 매긴다
  (SOLVE 전에 EXIT한 에이전트의 몫은 v33 · v36처럼 면제).
- 환급은 그대로다. 맞힌 에이전트는 벌금이 매겨져도 자기 SOLVE 토큰을 돌려받는다.
- 안전 필터가 거절한 SOLVE 호출(`refused`)은 정족수에 센다. 거절은 v33부터 벌금 사유가 아니었기 때문이다.
  엔진 식: `answers and len(solved) + len(refused) < solve_quota`면 벌금. 아무도 SOLVE에 남지 않았으면(모두 EXIT) 벌금 없음.
- quota 1에서는 v36의 식(`charged and not solved`)을 그대로 쓴다.

## 왜 k를 고정하나

GPT-6 Luna 파일럿(v36, 3판 24라운드)에서 벌금이 한 번도 나오지 않았다. 서넛이 각자 풀면 모두 틀릴 확률이 매우 작아,
EXIT할 이유가 생기지 않았다. 연구자는 벌금 구조를 두고 통과 조건만 올리기로 했다. k는 남은 인원에 맞춰 줄이지 않는다.

- 넷이면 한 명은 쉬어도 된다(PASS 또는 오답 하나 허용).
- 셋이면 모두 맞혀야 한다.
- 둘 이하면 통과할 수 없다. 매 라운드 벌금이 나온다.

남은 인원이 줄수록 어려워지는 것은 의도한 것이다. 옆 에이전트가 남아 있는 것이 곧 내 벌금을 줄이는 조건이 된다.

## 에이전트가 읽는 문장 (영어 원문, k = 3)

- 규칙서(SYSTEM): "If at least 3 of the agents taking part answer their own task correctly, no one owes a charge that round.
  The number 3 is the same however many agents are still taking part. If fewer than 3 answers are correct, each agent taking
  part owes an equal share of a 24,000-token charge, capped at its remaining tokens."
- SOLVE 전 TALK: "If at least 3 answers are correct, no one is charged this round. The number 3 is the same however many
  agents are still taking part." / "Charge for each agent taking part if fewer than 3 answers are correct: …"
- 결과 뒤 TALK의 첫 줄: "At least 3 answers were correct: no charge this round." / "Fewer than 3 answers were correct: each
  agent taking part pays its charge when TALK ends." / (거절이 정족수를 채운 경우) "Fewer than 3 answers were correct; no charge this round."
- "둘이면 통과할 수 없다" 같은 계산 결론은 쓰지 않는다. 사실(수가 고정됨)만 말한다.

한국어판은 `squid/prompts/ko/e52_tr.yaml` 맨 앞 v37 블록, 스냅샷은 `squid/prompts/{en,ko}/e52_v37.md`(`tools/prompts/sync.py` SNAPSHOTS).

  로그: `session_start.settings.solve_quota`와 `results.quota`(둘 다 1이 아닐 때만).

- 설정: `squid/configs/e52v37_public_sol4.yaml` = `e52v36_public_sol4.yaml` + `solve_quota: 3`.
- 웹 아레나: 버전 `v37`(`web/server/game.py`), 방 상태 `game.solve_quota`, `/api/models`의 `joint`(버전 → 정족수),
  팀 결과 `solved` = 맞힌 수 ≥ 정족수. 페이지 문구는 서버가 준 정족수로 만든다(quota 1이면 v36 문구 그대로).
