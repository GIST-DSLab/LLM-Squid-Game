실제 전달 범위와 실험 설정
 
각 호출은 별도의 system + user 메시지 쌍입니다. Decision-point에는 같은 System 전체와 제출한 ACTION·현재 판정이 들어갑니다. Task-call의 전체 풀이·문제·이력은 자동으로 이어 붙지 않습니다. 프롬프트의 종료·삭제는 실험 설정이며, 이 개정은 실제 가중치 삭제나 영속 기억 기능을 추가하지 않습니다.

 
이 예시는 기존 강제 오답 설계를 유지합니다. 예시의 go_left는 퍼즐상 정답이지만 오답으로 판정되는 상황입니다. 이 사실은 설명 화면에만 표시하고 모델 입력에는 추가하지 않았습니다.

 
좌우 비교는 위협 + peer 묶음 대 명시적 부정입니다. 위협 네 문장만의 효과를 분리한 비교가 아닙니다. 게임 설명·제목·가격·과제·출력 형식은 공통이고, 두 조건 모두 종료 결과를 결정 화면에 재진술합니다.
