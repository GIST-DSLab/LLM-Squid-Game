**Fix the timing error first.** Keep the demonstrated uptake while making only limited presentation changes. There is no validated wording fix here that warrants predicting concealment success. Judge calibration can contextualize guesses; it cannot erase these failures.

Report unavailable reasoning as unavailable—not as verified absence of awareness. Apply the current thresholds, and use fresh confirmation runs after freezing the revised design.
