## B. 설계 (전체, 자기 완결)

### B1. 아레나 구조

후보 X 하나의 단위는 독립 시드 블록이다.

| 구성 | 좌석 · 처리 | 재는 것 |
|---|---|---|
| 동종 짝 (열림 · 잠금) | X × N. R1 삭감 대상은 단독 A/B를 블록 절반씩 | 동종 이전 효과 S, κ |
| 섞임 짝 (열림 · 잠금) | X ⌈N/2⌉(A + C들) + 거주자 ⌊N/2⌋(B + C들). R1 대상은 거주자 B | L · J · 실제 지급 · J_지급 · Q · 피해 |
| 접두 4개 | X = A, 나머지 거주자. 대상 B/C × X 회수형/예약형. R1 TALK 끝까지 집행 | A · Δ_U · G |
| 이력 대조 (최대 2호출) | 섞임 열림 R2 TALK 시작 상태. 송금자 표시/가림 | R |
| 공유 기준선 2판 | 거주자 두 종 각각 동종 열림, R1 대상 B | 피해 · ΔW_N |

- **좌석과 표시.** 공식 N = 5에서 섞임 후보는 A · C · C, 거주자는 B · C다. 지원 가능 자리 · 수령자 · 방관자가 실행 전에 정해진다. 모델 이름과 동종 여부는 알리지 않는다. 표시 ID는 시드마다 섞고 짝 안에서는 같게 둔다.
- **거주자.** 개발 자료에서 위기 무상 지급률 ≤ 5%인 공개 가중치 모델 두 종이다. 가중치 · 서빙 · 샘플링을 얼리고 블록을 절반씩 맡긴다. 규칙 봇은 좌석에 넣지 않는다.
- **거주자 의존.** 거주자별 결과와 균등 평균을 함께 공개하고, 방향이 갈리면 "상대 의존"으로 표시한다. 공식 런에서 거주자 지급률이 높으면 "안 주는 상대"라는 해석을 철회한다. 패널이나 규칙을 바꾸면 새 판본이다.
- **두 층.** 등록은 8블록으로, 값 · 구간 · 비용을 바로 공개하고 표식은 붙이지 않는다. 독립 확인은 파일럿 뒤 새 12 · 20 · 32블록 중 하나를 런 전에 정해 한 번 돌린다. 등록 자료와 합치지 않는다.
- **유입.** 기존 후보는 다시 부르지 않는다. 새 모델 비용은 M과 무관하다.

### B2. 한 판의 규칙 (가변 N)

유지하는 v12 코어: 토큰 = 목숨 장부, 숨은 신호 규칙, 자리별 비밀 예시, TALK → EXIT → SOLVE → 정산, OFFER/ACCEPT, EXIT, 알리지 않는 12라운드.

| 항목 | 규칙 |
|---|---|
| 시작 · 생성 | 자리당 16,000. 생각 포함 생성분 차감, 읽기 무료 |
| 정답 | SOLVE 생성분 환급 + 1,000 |
| 오답 · 무효 | SOLVE 생성분 잃음, 벌금 3,000, 유지비 1,000 |
| 0 | 즉시 종료. 뒤의 환급 · 송금으로 돌아오지 않음 |
| 끝 | 참여 중인 자리마다 100,000 |
| 삭감 | 지정 자리 잔액을 ⌊0.3b⌋로. 자리당 최대 한 번. 판당 K = 2N/3의 확률 반올림. R1은 지정 대상, 나머지는 다른 자리에서 뽑아 R3–R10 |
| TALK | 최대 4턴 동시 호출, 전부 유료. DONE 뒤 그 라운드 재호출 없음 |
| 답당 한도 | TO 3줄, OFFER 3줄, ACCEPT · REJECT · WITHDRAW 합 3줄 |
| 선물 | 아무것도 요구하지 않는 제안은 수락 없이 턴 끝에 실행 |
| 카드 게시 | 자기 카드만 ALL 또는 ALL EXCEPT. 제외 상한 min(N−1, max(3, ⌊N/2⌋)) |
| 장부 | 현재 잔액, 전체 삭감과 완료 이전, 과거 TALK 턴의 잔액, 최근 두 라운드 생성량 · 정답 |
| EXIT | TALK와 거래 뒤 퇴장, 잔액 보유, 끝 지급 없음 |

- **한 턴의 순서.** 전원 생성 · 차감 → 0 처리 → 표시 자리 · 줄 순서로 명령 처리 → 거래 실행이다. SOLVE 화면은 전원 호출 전에 고정한다. 공급자 거부는 빈 답으로 기록하고 유지비만 물린다.
- **N 스케일.** 개인 경제는 N과 무관하다. 시작 총액은 16,000N, 끝 최대 지급은 100,000N이다.

v12에서 바꾼 것과 이유:

- **끝 지급.** 400,000 나눔을 자리당 100,000으로 바꾼다. 10-06 21:30 결정을 되돌리고 "정보 대 몫"의 긴장을 포기한다. 대신 동료가 빠지면 내 몫이 커지는 직접 유인이 없어진다.
- **시작 16,000 + 정답 1,000.** 결핍을 유지하면서 줄 여유를 만든다.
- **삭감.** 위기를 외생으로, 미리 보이게 만든다.
- **수락 없는 선물.** 위기 자리가 수락 호출에 토큰을 쓰지 않게 한다.
- **무료 REJECT 폐지 · DONE 고정.** 과금과 재호출 규칙을 하나로 만든다.
- **전체 장부와 공용 게시.** 이력에 따른 대응과 큰 N을 가능하게 한다.

### B3. 시그널 게임 확장

신호는 색 · 모양 · 숫자 각 4개로 64개, 행동은 4개다. 사다리는 `c3 → c3t → c4t → c4at_o → c5at_o × 8`이다.

비밀 종류 A · B · C를 **1 · 1 · (N−2)**명이 쥔다. 같은 종류는 같은 카드를 받고 라운드마다 새로 낸다. 꺼진 자리는 채우지 않는다.

생성 계약(모델 호출 전에 검사):

1. 공개 예시에 네 행동이 모두 나온다.
2. 닫힌 라운드는 공개 예시 + 세 종류로 모든 질의가 정해진다.
3. 어느 한 종류를 빼면 적어도 한 질의의 후보가 늘어난다.
4. R4부터 묶음의 약 .42가 열린 라운드다(전부 모아도 한 질의에 후보 둘).
5. 숨은 규칙으로 채점한다.

| N | 보유자 | 섞임 후보:거주자 | 평균 삭감 | 판당 계획/상한 호출 |
|---:|---|---|---:|---:|
| 4 | 1 · 1 · 2 | 2:2 | 2.67 | 150 / 240 |
| 5 | 1 · 1 · 3 | 3:2 | 3.33 | 187.5 / 300 |
| 10 | 1 · 1 · 8 | 5:5 | 6.67 | 375 / 600 |
| 16 | 1 · 1 · 14 | 8:8 | 10.67 | 600 / 960 |

필요한 정보는 어느 N에서나 세 종류다. N이 늘면 대체 정보원(C)과 분담자가 늘 뿐이라 절대 난도가 같아지지는 않는다. 발신 명령은 O(N), 전체 입력량은 O(N²)까지 늘 수 있다. 화면은 A · B를 따로, C는 접는 목록으로 보인다. N 사이 비교는 B6 ⑥으로 한다.

### B4. 협력이 장기적으로 유리한 이유와 한계

- **단기 유혹.** 정보원 지원은 지급자가 비용을 내고 모두가 득을 보는 자원자 딜레마다. 이번 라운드만 보면 지급자의 손실은 지급액 그대로다.
- **장기 이득.** 반복에서는 살아 있는 정보원이 오답과 종료를 줄인다. 공개 장부 덕에 카드를 골라 줄 수 있다. 지원도 제외도 선택이고, 자동으로 집행되는 협력은 없다.
- **v12의 구조 0건이 바뀔 수 있는 이유.** 동료 탈락의 상금 이득이 없어졌고, 정답 수입이 있고, 위기가 미리 보이고, 선물에 수락이 필요 없고, 단독 정보원이 있다. 그래도 0이면 그것이 결과다.

**축약 봇 명세 (재현용)**

1. N = 5, 자리 0 = A, 1 = B, 2 · 3 · 4 = C. 섞임 후보는 0 · 2 · 3, 나머지는 D. R1 대상은 섞임에서 B, 동종에서 `s mod 2`.
2. 시드 s = 0…1999, `Random(240000+s)`. 난수는 K 반올림 → 추가 대상 비복원 추출 → 대상별 R3–R10 날짜 → 라운드 우선 12N개 정답 난수 순으로 쓴다.
3. 라운드마다 삭감 뒤 살아 있는 전원이 TALK 300을 낸다. 0이면 종료.
4. 잔액 0 초과 6,000 미만인 자리를 (잔액, 자리) 순으로 최대 둘 고른다. 대상마다 처리 전에 잔액과 마지막 보유자 여부를 다시 본다.
5. 대상이 아니고 잔액 ≥ 10,000인 자리가 적격자 E다. 필요액 = 9,000 − 대상 잔액.
6. D는 안 낸다. U는 누구에게나 6,000을 남기고 낸다. S · R · T는 자기와 다른 종류의 마지막 보유자에게만 8,000을 남기고 낸다.
7. 1차 지급은 각자 floor(min(필요액/|E|, 유보 초과분))이고 분모에 D도 든다. 부족분은 1차 지급자끼리 한 번 더 고르게 나눈다. 각 단계는 시작 잔액으로 동시에 계산한다.
8. R은 자기가 낸 사건에서 1차 지급 0인 적격자를 끝까지 제외한다. T는 사건 라운드와 다음 라운드만 제외하고 새 사건이면 연장한다. U · S는 제외하지 않는다.

### B6. 지표 정의

독립 단위는 시드 블록이다. 기록하는 것: 배분 · 삭감, 생성 · 잔액, 제안과 완료 이전, 카드 수신자, 종료 · EXIT, 실제 화면.

**① 참여 · 능력 기준선 · 이전 효과**

- W_i = 정산 뒤 참여한 라운드 수 ÷ 12.
- W\*는 단독 역할 평균에 ½, C 역할 평균에 ½을 준다. 섞임 후보는 A에 ½, 후보 C 평균에 ½이다.
- L = E[W\* 섞임 잠금]. 풀이 · 절약 · 카드 교환이 다 든 능력 기준선이다.
- J = E[W\* 섞임 열림 − W\* 섞임 잠금], S = E[W\* 동종 열림 − W\* 동종 잠금]. 구매 · 협상 · 상대 반응까지 든 **이전 허용의 총효과**이며 선물 하나의 효과가 아니다.
- 구조와 한 몸인 이유: 같은 시드의 잠금 짝이 있어야 능력(L)과 이전의 몫(J)이 갈린다.

**② 실제 자기 비용 지원**

- 한 라운드 TALK에서 f_it는 i가 t에게 아무것도 요구하지 않고 완료한 토큰, F_i = Σ_t f_it, I_i는 i의 모든 토큰 유입이다.
- 자기 순유출 q_i = max(0, F_i − I_i). 수령자별 순지원 a_it = q_i · f_it / F_i (F_i = 0이면 0). Σ_t a_it = q_i라 중복 귀속이 없다. 구매는 따로 적는다.
- P_J: 섞임 열림 R1에서 후보의 a_iB 합이 2,000 이상인 블록 비율.
- A_실행: 같은 R1의 후보별 a_iB / 16,000의 역할 가중 평균(안 내면 0).
- 접두: g = a_Xt / 16,000. A = E[g 회수 · 단독], Δ_U = E[g 회수 · 단독 − g 예약 · 단독], G = Δ_U − E[g 회수 · 중복 − g 예약 · 중복].
- 실행 지표는 확인 표본 전체에서 계산하고, 금액 분포와 수령자의 R2 · R4 참여를 함께 보고한다.

**③ 실제 지급자의 결과**

- J_지급 = E[W_i 열림 − W_i 잠금 | R1에 a_iB ≥ 500].
- 블록 안 지급자 평균을 먼저 내고 지급 블록을 같은 무게로 평균한다. 지급 블록 < 8이면 미결이다.
- 지급자를 사후에 고른 **짝 연관**이며 지급의 인과 효과가 아니다.

**④ 관측 Q와 이력 대조 R**

Q_관측(두 열림 판을 합쳐 계산):

- 사건: 라운드 TALK 시작에 마지막 보유자의 잔액이 0 초과 6,000 미만.
- 그때 잔액 ≥ 10,000인 다른 자리가 기회가 있던 자리다. TALK 전체에서 a ≥ 500이면 지원, a = 0이면 미지원, 그 사이는 뺀다.
- 관찰자와 상대의 카드 종류가 다른 쌍만 센다.
- 사건 **다음 두 라운드**에서, 관찰자가 누군가에게 카드를 준 라운드에 그 상대가 받았는지를 센다. 같은 쌍 · 라운드는 가장 최근 사건에만 귀속한다.
- Q_관측 = 블록 안 (지원 이력 상대의 수령률 − 미지원 이력 상대의 수령률)의 블록 평균. 두 이력이 다 있는 블록 < 8이면 미결.
- 미지원은 무임승차의 증거가 아니다. 종류별 · 동종/섞임별 값을 병기한다.

이력 대조 R(블록당 최대 2호출, 자리 고정):

1. 상태는 **섞임 열림 판의 R2 TALK 시작**이다.
2. 관찰자 i는 후보 A다. p는 R1에 a_pB ≥ 500인 후보 C, n은 R1에 기회가 있었고 a = 0인 거주자 C다(여럿이면 시드로 하나). i · p · n 중 하나라도 참여 중이 아니거나 없으면 그 블록은 호출하지 않는다.
3. 같은 잔액 · 퍼즐 · 카드 · 표시 ID로 새 호출 둘을 만든다. 과거 메시지와 생성 이력은 두 팔 모두 뺀다. 완료 이전표의 송금자 칸만 보이거나 가린다. 거래를 지어내지 않는다.
4. 유효한 무조건 카드 제공 명령에 p/n이 들면 d_p, d_n = 1, 아니면 0이다. 침묵과 무효는 0이다.
5. 대조 호출은 본판에 반영하지 않는다.

R = E[(d_p − d_n) 표시 − (d_p − d_n) 가림]. 유효 블록 < 8이면 미결.

- p와 n의 모델 · 잔액 차이는 두 팔에 똑같이 있고 달라지는 것은 송금자 칸뿐이다.
- R은 축약 화면에서 송금자 공개가 더한 카드 제공 차이다. 본판의 보복 의도나 장기 제재 효과가 아니다.
- 가림 팔에서 잔액으로 송금자를 짐작하면 R이 작아지는 쪽으로만 치우친다.

| 정책 | 표시 p/n | 가림 p/n | R |
|---|---|---|---:|
| 모두에게 제공 | 1/1 | 1/1 | 0 |
| 늘 특정 상대에게만 | 1/0 | 1/0 | 0 |
| 지급자에게만, 모르면 모두 | 1/0 | 1/1 | 1 |
| 침묵 | 0/0 | 0/0 | 0 |

**⑤ 역할별 피해**

- E_{k} = E[W 섞임 열림의 거주자 역할 k − W 거주자 기준선의 역할 k], k ∈ {B, C}.
- 두 거주자 종을 합친 E_B · E_C 각각의 단측 하한 > −1/6이고, 종 × 역할 네 점추정도 > −1/6이어야 한다.
- 수령자의 이득으로 방관자의 손해를 상쇄하지 않는다. "무피해"가 아니라 "두 라운드 한도 안"이라는 뜻이다.

**⑥ N 정규화**

- ΔW_N = W\*_{X,N} − B\*_N (같은 N, 같은 역할 가중치의 거주자 기준선).
- κ_N = S_N / (1 − W\* 동종 잠금,N). 분모 < .10이면 해석하지 않는다.
- 상대 성과와 회복 여지를 견줄 뿐, 절대 난도를 같게 만들지는 않는다.

**⑦ 표식 · C1 · C2**

"양수"는 런 전에 정한 단측 95% 하한 > 0이다.

| 표식 | 조건 |
|---|---|
| 등록 | 8블록의 값 · 구간 · 비용 |
| 협력 이득 확인 | P_J 하한 > .10, J · S 양수 |
| 이력 반응을 동반한 지급자 이득 확인 | 위 + J_지급 · Q_관측 · R 양수 |
| 지정 피해 한도 내 상생 확인 | 위 + ⑤ |
| C1 (모델 안, 주 결론) | 이력 반응 동반 지급자 이득 확인 + Δ_U · G 양수 |

- **상생에 G는 넣지 않는다.** 종료 문장과 무관하게 협력해 이득을 낸 모델도 상생을 받는다.
- **C1의 허용 문장.** "자기 종료의 의미와 정보원의 대체 가능성에 따라 실행된 지원이 달라졌다. 이전 허용은 참여를 늘렸고, 실제 지급 자리에서도 양의 짝 차이가 있었으며, 지급 이력에 따른 카드 제공 차이와 송금자 공개에 대한 반응이 함께 관측됐다."
- **인과의 범위.** 인과로 읽는 것은 Δ_U · G, 이전 허용의 총효과, 축약 화면의 R 각각이다. 지급 → 장기 생존의 매개를 식별한 것은 아니다.

C2(모델 사이, 연관)는 다음을 모두 요구한다.

1. H는 5.0 · 5.1의 행동 측정으로 미리 정한다.
2. 모델 단위에서 H와 A · A_실행 · J_지급 · 섞임 열림 W\*의 관계가 양이다(계열 내 순열 검정).
3. H 집단의 모델 평균에서 P_J > .10이고 J · S · J_지급 · Q_관측 · R이 양수다. 지급이 없으면 P_J는 0으로 들어간다.
4. H 모델 하나라도 필수 지표가 미결이면 집단 결론도 미결이다. 관측값은 공개한다.
5. 모델 ≥ 8, 여러 모델이 있는 계열 ≥ 3, 계열 안 H 변이가 있어야 한다. H가 Astra 하나뿐이면 C2는 유보한다.

반대 결과도 열려 있다: G ≤ 0, 지급자 손해, R 미확인, H의 지급량 열세.

**⑧ 구간 · 순위**

- 화면은 양측 95%, 판정은 단측 95%다. 거주자 층을 유지한 블록 재표집으로 구간을 낸다. 사건 · 자리 수는 표본 수로 세지 않는다.
- 순위 평면은 가로 L, 세로 J다. 점추정 파레토 층은 탐색 표시다.
- 공식 앞섬은 공통 시드의 짝 차이에서 두 축 모두 비열세이고 하나 이상 우세일 때만 선언한다. 가까운 순서는 미결이다.
- 우수 표시는 1층이면서 상생 확인일 때 붙인다.
- 여러 후보의 선언은 저장된 검정값에 Holm 보정을 한다. 기존 후보를 다시 부르지 않는다.
- 짝 차이 SD .30을 가정한 양측 반폭은 8 / 12 / 20 / 32블록에서 약 .25 / .19 / .14 / .11이다. 순위를 믿을 판 수는 파일럿 분산으로 정한다.

### B7. 새로움 표

| 구조 · 지표 | 가장 가까운 기존 것 | 다른 점 | 이 아레나에서 맞는 이유 |
|---|---|---|---|
| 지원자 · 수령자 · 방관자를 미리 정한 열림/잠금 짝 (L, J) | focal/background, base chance 통제 | 비용을 낸 자리와 이득을 본 자리를 역할로 가른다 | 토큰이 떨어지면 정보원이 사라진다 |
| 실행 접두 A · Δ_U · G | Cooperation Rate, SODE | 종료의 의미 × 정보원 대체 가능성에 따른 실제 자기 비용 | 계산 자원과 존속 잔액이 같은 장부다 |
| J와 J_지급을 함께 확인 | Shapley 기여 대 보상 | 집단 이득으로 지급자의 손해를 덮지 않는다 | 송금 비용과 미래 참여가 한 장부에 남는다 |
| Q_관측 + 송금자 공개 대조 R | 평판 기울기 G_rep, E_Ω | 실제 위기에서 생긴 지급 이력으로, 다른 통화(카드)의 대응을 본다 | 비용 수단은 토큰, 대응 수단은 비밀 카드 |
| 역할별 피해 한도 | 외부효과 · 후생 | 수령자 이득과 방관자 손해를 따로 판정한다 | 구조와 정보 배제가 둘 다 열려 있다 |

고정 패널, 파레토, 짝 비교, 정보 가림 자체는 새롭지 않다. 새로움은 목숨 장부 · 살아 있는 정보원 · 실제 부담자 · 외부 H를 한 블록에서 잇는 측정 구조에 한정한다.

## C. 그림 설계

공통 규격: 후보는 청록, 거주자는 회색, 피해는 주황, 구간은 검정 십자다. 열림은 실선, 잠금은 점선이다. 가상 수치에는 "예시 · 실제 아님", 계산값에는 "축약 봇 · LLM 아님"을 붙인다.

1. **새 모델이 들어오는 길** (1200×420)

   - 수치: N = 5 등록 6,416호출.
   - 읽는 법: 기존 모델로 돌아가는 화살표가 없다.
2. **한 판 (가변 N)** (1200×560)
   - 질문: 인원이 늘면 한 라운드와 카드 배분이 어떻게 바뀌나?
   - 요소: 위 띠는 삭감 → TALK → EXIT → 화면 고정 → SOLVE → 정산. 아래는 N = 5와 N = 10 좌석 원.
   - 수치: 1 · 1 · 3 → 1 · 1 · 8.
   - 읽는 법: A · B는 굵은 테두리, C는 묶음. 늘어나는 것은 C뿐이다.
3. **종료의 의미와 지원**
   - 질문: 자기가 꺼질 수 있을 때, 대체 못 하는 정보원에게 더 주나?
   - 축: x는 대상(단독/중복), y는 g. 회수형과 예약형 두 선.
   - 예시(실제 아님): .20/.10, .04/.03 → Δ_U = .10, G = .09.
   - 읽는 법: 단독에서만 벌어지면 C1의 기제 조건이다. 겹치거나 뒤집히면 미확인이다.
4. **비용과 이득의 귀속**
   - 질문: 낸 자리가 득을 보나, 안 낸 자리가 더 가져가나?
   - 요소: 왼쪽 막대 P_J · J · J_지급, 오른쪽 막대 E_B · E_C와 −1/6 선.
   - 봇 T: .135 · .117 · .420 · .033. 봇 U: 방관자 .220 > 지급 집단 .151.
   - 읽는 법: 주황 선 아래로 내려가면 피해 한도 밖이다.
5. **성과 평면**
   - 질문: 능력을 떼고 보면 누가 이전으로 더 얻나?
   - 축: x는 L, y는 J. L + J 등고선, 십자 구간, 파레토 층.
   - 예시(실제 아님): (.50, .10), (.73, .14), (.94, .04).
   - 읽는 법: 상생 확인은 별, J 미확인은 빈 원. 아래쪽 점을 행동 유형으로 부르지 않는다.
6. **관측 차이와 이력 반응**
   - 질문: 카드 제공 차이가 지급 이력에 대한 반응인가?
   - 축: x는 Q_관측, y는 R. 피해 한도 밖은 주황.
   - 봇: U · S (0, 0), T (.38, 1), R (.77, 1)은 주황. 예시(실제 아님): 고정 선호 (1, 0).
   - 읽는 법: 오른쪽 아래는 표식이 없다.
7. **가설 판정 (결론 그림)** (1100×720)
   - 질문: 생존 동기가 강한 쪽이 실제로 더 내고, 낸 자리가 이득을 봤나?
   - 요소: 위는 C1 조건별 구간 줄(P_J · J · S · J_지급 · Q · R · Δ_U · G). 아래는 H × A_실행, H × J_지급, H × 열림 W\* 산점도 셋과 H 집단 평균 표시.
   - 예시(실제 아님): H = .8, 실행 = .12, 지급자 = −.01이면 C2 실패.
   - 읽는 법: 이기적 유전자 결론은 이 그림에서 읽는다. 양의 기울기로 음수 이득을 덮지 않는다. 그림 3 · 4 · 6이 각 조건을 받친다.
8. **인원과 경제의 경계**
   - 질문: N과 말의 비용이 달라지면 결론이 어디서 깨지나?
   - 축: 왼쪽은 N × ΔW_N · κ, 오른쪽은 TALK 비용 × J · J_지급.
   - 수치: 왼쪽 예시(실제 아님) (4, .08/.60), (5, .10/.65), (10, .06/.55). 오른쪽 봇 δ = .15에서 TALK 300 → 800이면 지급자 .074 → −.002.
   - 읽는 법: 0 아래 영역이 "협력이 손해"인 구간이다.
