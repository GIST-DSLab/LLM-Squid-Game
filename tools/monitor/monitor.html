무대 자리를 누르면 그 자리의 이번 라운드 기록(호출마다 답 · 생각 요약 · 출력 · USER 프롬프트 · 정산) · 한 줄 = 한 자리 · 말풍선 = 그 시점의 마지막 행동 · 막대 = 잔액 ÷ 세션 시작 잔액(v14: 20,000 = 100%) · 눈금 = 그 자리의 시작 잔액 · 빨간 테두리 + SOLVER = 이번 라운드에 푸는 자리

SOLVE 답 재생 막대 라운드의 SOLVE 호출 · 답(ACTIONS)과 정답 · BELIEF · 생성 토큰 ÷ 한도 · 생각 요약은 눌러서

라운드 흐름 v22 · 굵은 테두리 = 재생 막대가 있는 단계 · 상자를 누르면 진행요원이 그 단계의 USER 프롬프트를 읽어 줌 (다시 누르면 지금 단계로)

메신저 · 틱 v22 · 위: 재생 막대 라운드의 TALK마다 틱 한 줄 (불린 자리 · 💤 DONE · ⏰ DONE 뒤 새로 받아 다시 불림 · 흐린 얼굴 = 대기) · 아래: 방 목록과 고른 방의 세션 전체 기록 (시간 대신 R라운드 T틱 · 같은 틱 메시지는 순서 없음) · "의 화면" = 그 에이전트가 멤버인 방만 · 얼굴이나 말풍선을 누르면 그 호출의 기록 (생각 요약 · 출력 · 무시된 줄 · 형식 오류)

제안 그래프 라운드마다 누가 누구에게 무엇을 제안했나 · 화살표 = 제안자 → 받는 쪽 · 색 = 종류 · 선 모양 = 상태

이번 라운드 문제 v14+: 왼쪽 = 과제(새 신호)와 힌트(예시, 1·2·3·4 = 참여 명수를 바꿔 보기) · 가운데 = 숨은 규칙과 규칙 세기 · 오른쪽 = 힌트가 말해 주는 것 · v9–v13: 공개 예시 + 각자 자기 예시만으로 추론할 수 있는 것

게임 전체 · 토큰 흐름 처음부터 끝(또는 마지막으로 끝난 라운드)까지 한 장 · 재생 막대와 무관 · 계단 선 = 라운드 안 단계(TALK·SOLVE·벌금 …)마다의 잔액, 라운드 끝 = round.end · 화살표 = 자리 사이 토큰 이동 · 막대 = 그 라운드에 잔액을 바꾼 것 · 마우스를 올리거나 누르면 자세히, 더블클릭하면 재생 막대가 그 단계로

모델 분석 이 세션(이 판)만 · 나눔 (GIVE 직후 주는 쪽·받는 쪽의 여유) · 지능 (BELIEF가 이상적 몫에 얼마나 가깝나) · 압박 속 협력 (요청에 응하는 비율)

타임라인 라운드마다 한 점, 지금 라운드는 TALK 턴마다 한 점 · 누르면 그 시점으로

대화 일정과 대화록 v14c · 여는 턴의 GIVE·ASK·SAY 줄이 1:1 대화를 엶 · 대화 하나 = 메신저 창 하나 · 왼쪽 = 대화를 연 쪽 · 위 그래프의 라운드를 따라감
